## Workflow and layers

Owner opens private edit read endpoint then PATCHes changed fields with expectedVersion. Unknown/forged fields rejected. Partial PATCH merges into stored values, validates the resulting event and preserves omissions; capacity omission on legacy >60 does not block unrelated permitted edits. Existing event must not have started and proposed start remains future. End>start, mandatory/text rules unchanged. Deadline null uses startsAt; explicit deadline<=start; past deadline closes immediately. At now>=effective cutoff registration fails, including exact equality; own existing ACTIVE duplicate still returns ALREADY_REGISTERED first.

UI edit form is separate from Create Event component where practical, linked from My Events/owner detail. Show current version/cutoff in meaningful copy without implementation jargon; pending disables submit,422 highlights fields,409 edit conflict asks reload/review without silently resubmitting. Do not send unchanged capacity field on a legacy event unless user explicitly chooses to change it. Public detail/register availability displays Closed when cutoff reached; backend clock decides. Error/expired session clears private state. All time controls display Asia/Bangkok and serialize UTC.

New event deadline/version schema, owner DTO/routes/error precedence, shared schedule mutex/event lock and overlap algorithm follow [system design](system-design.md). Existing create contract is not extended to accept deadline by this feature; new events begin with null deadline and owner may set it through edit. No new environment variables, account management, delete/draft/unpublish, automatic mutation retries or stored seat counters.
